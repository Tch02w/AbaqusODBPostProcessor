# Qt 手动功能回归计划

当前尚不能声明 Qt 与 Tk 完全功能对等。以下步骤用于逐项验证。

1. 启动 `abaqussubmitQt.py`。
2. 选择 INP，确认输入框显示、Job 名称和命令预览正确。
3. 选择重启动 ODB，确认 `oldjob=` 参数正确。
4. 选择 FOR，确认 `user=` 参数正确。
5. 修改 Core、Mem `%/GB/MB`，确认命令预览正确。
6. 勾选 interactive、datacheck、结束提醒，确认命令和运行监控行为正确。
7. 提交普通 Job，确认 QProcess 输出、STA 读取、结束诊断。
8. 提交 Restart Job，确认依赖 ODB、前置任务和归档延迟逻辑。
9. 提交 Datacheck Job，确认不会按正式计算误判。
10. 测试暂停、恢复、终止。
11. 打开工作目录、STA、MSG、DAT。
12. 管理队列：加入当前 INP、多选 INP、扫描文件夹、扫描子文件夹。
13. 管理队列：全选、取消全选、反选、删除候选项、确认入队。
14. 管理队列：编辑待运行 Job、取消待运行 Job、终止运行中 Job、清理结束记录。
15. 设置最大并行数，验证自动补位。
16. 测试 Restart 依赖：前置运行中、前置完成、前置失败、多级 Restart。
17. 设置 SSD 工作目录和 ARC 归档目录，验证配置保存与恢复。
18. 验证 INP 复制、已有 ODB/LCK 处理、结果归档和临时目录清理。
19. 扫描外部 Job，确认后台扫描时窗口可拖动。
20. 外部 Job 导入后，确认状态、内存、终止和结束诊断更新。
21. 运行多个 Job，验证内存 learning/patrol、Step 峰值和动态槽位。
22. 关闭并重启程序，确认 joblist.json 恢复不会把旧 JSON 直接当成运行中。
23. 运行期间关闭程序，确认没有 QThread 警告或后台异常。
